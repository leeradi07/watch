# 부산의 하루 — 새벽부터 밤까지

부산의 핫플레이스를 배경으로 장면이 전환되면서, 하나의 시계가 **05:00 → 23:00** 으로 흐르는 44초 영상입니다.

![](busan_dawn_to_night.mp4)

| # | 장소 | 시간대 |
|---|------|--------|
| 01 | 해운대 해수욕장 — 수평선 위 일출 | 새벽 05:00 ~ |
| 02 | 해동용궁사 — 바다 위 사찰과 연등 | 아침 |
| 03 | 감천문화마을 — 어린왕자와 사막여우 | 오전 |
| 04 | 해운대 블루라인파크 — 스카이캡슐, 청사포 쌍둥이 등대 | 오후 |
| 05 | 용두산공원 부산타워 · 자갈치 — 항구의 노을 | 해질녘 |
| 06 | 광안대교 — 무지갯빛 조명과 드론쇼 | 저녁 |
| 07 | 마린시티 — 야경과 불꽃놀이 | 밤 ~ 23:00 |

- 사진을 쓰지 않고 모든 장면을 코드로 그립니다(`busan_day.py`).
- 하늘색, 주변광, 해·달·별, 창문 불빛이 시각에 맞춰 연속으로 변하고, 장면 사이는 빛이 쓸고 지나가는 와이프로 전환됩니다.
- 오른쪽 위 시계 HUD와 아래 하루 진행 막대가 시간 흐름을 보여 줍니다.
- 배경음(패드·벨·파도·불꽃 소리)도 코드로 합성합니다.

## 다시 만들기

```bash
pip install numpy pillow opencv-python-headless   # ffmpeg 필요
python3 video/busan_day.py                          # 1920x1080 → video/busan_dawn_to_night.mp4
BUSAN_W=960 python3 video/busan_day.py              # 빠른 미리보기
python3 video/busan_day.py --still 3 20 35          # 특정 시각(초) 정지 화면만 PNG로 저장
```

글꼴(Noto Sans KR)은 처음 실행할 때 Google Fonts 에서 `video/fonts/` 로 내려받습니다.
